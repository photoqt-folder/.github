# PhotoQt - Look at Photos You May Open

At a glance:
- A folder of images you choose
- Zoom and a slideshow that do not have to save
- Metadata you can read and then leave
- Close without a new file time

## The Folder

PhotoQt is a viewer. You point it at a directory, step through pictures, and leave them on disk. Fit-to-window shows the whole frame. Actual size shows whether the photo is soft. Use actual size once before you reshoot or re-export.

Stay in the folder you opened. A path on a shared drive is not yours because you can see it. Private pictures should not stay on screen when you leave the desk. PhotoQt does not include a stock library and does not remove a watermark you did not make.

## Metadata You Read

The info panel can show a date or a camera note stored in the file. Reading it is not an edit. If a location is present, treat it as private. Do not publish it by accident, and do not collect coordinates from images you should not have. Closing the panel should not rewrite the photo.

If you want the location gone from a picture you will post, do that on a copy in a tool you mean to edit with, then check the copy. PhotoQt's job here is to let you see the tag, not to batch-strip a folder you do not own.

## Slideshow And Cache

A slideshow plays the folder you already chose. It is for a review, not for a meeting of pictures you cannot show. A cache can make the next open faster. Clearing the cache removes thumbnails, not the photos. If a file's modified time changes after a look, something saved. Restore the original before you continue.

## Do Not Overwrite

There is no need to save a view. If a dialog offers to write the same filename, cancel. The camera file or the scan stays the master. A converted copy, if you make one elsewhere, gets a new name and is checked at actual size.

## One Card, Then The PC

Copy the card to a folder first if these are the only files. Browse the folder, not the card, until you know the viewer will not write. Delete from the card only after the computer copy has opened and you have a backup you trust.

## Shared Desk

Quit PhotoQt when you stand up if the last image was private. A fullscreen slideshow left running is still a display of those files. The next person should not see them because you forgot the window.

## Player Profile

PhotoQt fits a review of pictures you took or were asked to check. It does not fit an overwrite, a card you have not copied, a shared folder that is not yours, or a harvest of locations from other people's images.

## Help Desk

The picture looks soft? Switch to actual size. Fit-to-window shrinks the frame.
The file time changed? You saved. Restore the copy.
Metadata shows a place you did not want public? Do not post that file. Edit a copy if you may.
The folder is someone else's? Close it.
The slideshow is the wrong set? You opened the parent directory. Open the shoot folder instead.

## Reader Notes

One folder and one actual-size look tell you whether the viewer is safe. The date in Explorer is the check. If it moves, stop using the tool on originals until you know which command wrote.

Metadata is a read. Treat GPS as private even when it is your own house. A viewer is a poor place to learn a batch delete.

Copy the card before a long review. The viewer can be quick. The only copy of a shoot should not be the thing you browse first.
